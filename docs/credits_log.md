# ElevenLabs credits log – Žingsneliai

Every ElevenLabs generation made for this project, so its spending stays separate from
other projects on the same account. All of it is in the flow
[Žingsneliai – Poros level 1](https://elevenlabs.io/app/flows/3tWgQ8SDuDoK3W4PaxmU),
unless the row says otherwise.

**Prices seen so far**
- Picture (GPT Image 2.5, high quality, 1K, **16:9**): **190.36 credits** each. The **1:1 square** format costs **337** – so we generate 16:9 and crop to square.
- Voice clip, text-to-speech (Eleven v4 / v3): **about 1 credit per character** of text,
  tags included ("Sudėk į krepšelius." = 19 credits, "[calm, gentle, neutral Lithuanian] Banãnas." = 43).
- Voice Changer (own recording → Žilvinas): billed by length of audio; see the ElevenLabs Usage page.
