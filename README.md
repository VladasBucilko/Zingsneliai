# Žingsneliai – Android test build

`zingsneliai.apk` – version 0.4.0 (prototype), built with Godot 4.7.1.
- Home screen with two sections: **Žaidimukai** (seven mini-games, incl. the new word riddle "Atspėk") and **Mano planas** (magnetic picture board).
Debug-signed for testing only (not for Google Play). Android 7.0+. Kartok asks for microphone permission.
