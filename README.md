# Žingsneliai – Android test build

`zingsneliai.apk` – version 0.3.0 (prototype), built with Godot 4.7.1.
- Home screen with two sections: **Žaidimukai** (six mini-games, one level each) and **Mano planas** (magnetic picture board, 6 spaces).
Debug-signed for testing only (not for Google Play). Android 7.0+. Kartok asks for microphone permission.
