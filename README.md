# Žingsneliai – Android test build

`zingsneliai.apk` – version 0.2.0 (prototype), built from the `claude/all-minigames` branch with Godot 4.7.1.
All six mini-games, one level each: Burbulai, Poros, Rūšiuok, Surask, Dėlionė, Kartok.
Debug-signed for testing only (not for Google Play). Android 7.0+. Kartok asks for microphone permission.
